
# BMI Calculator

## Project Overview
A beginner-friendly Python application that calculates
Body Mass Index (BMI) using weight and height.

## Features
- Accepts weight in kilograms.
- Accepts height in metres.
- Calculates BMI using weight / height squared.
- Displays BMI rounded to two decimal places.
- Classifies BMI as Underweight, Normal, Overweight,
  or Obese.
- Validates non-numeric, non-finite, zero, and negative inputs.
- Rejects heights greater than 3 metres to catch unit/input mistakes.

## Technologies Used
- Python 3
- Visual Studio Code

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run: python main.py
5. Enter your weight in kilograms and height in metres (for example, `1.70`).

## Formula
BMI = Weight (kg) / Height (m)²
